App Check CI reference

  1. Create a named debug token for the Riddle Quest web app in Firebase App Check.
  2. Store it only in a secret manager or temporary shell variable.
  3. Expose it as FIREBASE_APPCHECK_DEBUG_TOKEN to the test process.
  4. Inject it before browser page and iframe scripts execute.
  5. Revoke it immediately if disclosed.

Never commit the token, put it in a Vite variable, or add it to the Jest artifact.
