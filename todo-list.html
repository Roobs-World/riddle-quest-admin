Delete Account Flow

Summary

Add a bottom “Delete Account” action to the profile modal, show a content-sized confirmation modal, then call a new Firebase callable function that hard-deletes the current account. This will apply to both signed-in users and anonymous guest users. Keep todolist.html/todo-list.html updated with this task’s status as implementation progresses.

Key Changes

  • Add a danger-styled “Delete Account” button at the bottom of FullProfileDetailsModal, below Achievements/Stats/Leaderboard.
  • Add a dedicated confirmation modal that reuses the existing SlideInModalContent modal language, but avoids the current fixed InfoModal height so the sheet wraps its title, message, and buttons.
  • Confirmation modal behavior:
    • Cancel closes only the confirmation modal.
    • Confirm disables both buttons, shows loading text/spinner state, calls deleteAccount, then closes modals and runs the existing auth logout() cleanup.
    • Errors keep the user in the profile flow and show the existing info/error modal style.
  • Use getCallableFunction("deleteAccount") from src/utils/firebaseFunctions.ts so the client calls the existing us-central1 Functions region.
  • Add profile strings for delete button, confirmation title/body, cancel, confirm, loading, success, and error text.

Firebase Function

  • Add deleteAccount to firebase-functions/src/userManagement.ts and export it from firebase-functions/src/index.ts.
  • Callable uses onCall({ enforceAppCheck: true }).
  • Require request.auth.uid; ignore any client-supplied user id.
  • Hard delete:
    • Firebase Auth user for the authenticated UID.
    • users/{uid} and all subcollections, including known subcollections such as riddleStates and processedPurchases.
    • leaderboard/{uid}.
    • Any known user-owned top-level docs discovered during implementation.
    • Storage files under user-owned avatar/export prefixes where present.
  • Make deletion idempotent: missing docs/files/Auth user should not fail the whole request.
  • Log and throw HttpsError("internal", ...) only for unexpected deletion failures.

    • Pressing delete opens the confirmation modal.
    • Cancel closes confirmation without calling Firebase.
    • Confirm calls deleteAccount, shows loading state, closes flow, and calls logout().
    • Callable failure shows an error and does not force logout.
  • Add Firebase function tests:
    • Unauthenticated request is rejected.
    • Function only deletes request.auth.uid.
    • Deletes user doc/subcollections, leaderboard row, storage files, and Auth user.
    • Missing resources still return success.
  • Run targeted Jest suites and firebase-functions TypeScript check. For UI verification, use Expo/simulator verification if Expo MCP is available in execution mode; otherwise run the local React Native test coverage and document simulator manual checks.

Assumptions

  • Account deletion is permanent hard deletion.
  • Guest deletion means deleting the anonymous Firebase Auth account and using existing logout() behavior to clear guest local data.
  • Existing purchase/audit data under the user account is deleted as part of hard deletion.
  • The current fixed-height InfoModal is not reused directly because it conflicts with the requested content-sized height; the new confirmation modal will reuse the shared modal presentation primitives instead.

Client UI Tasks

  • Add delete button at the bottom of the profile modal.
  • Add delete account strings in AppStrings.
  • Create a content-sized confirmation modal using existing shared modal primitives.
  • Wire cancel, confirm, loading, success, and error states.
  • Call getCallableFunction("deleteAccount") from the confirm action.
  • Run existing logout() cleanup after successful deletion.

Firebase Function Tasks

  • Create deleteAccount callable with enforceAppCheck: true.
  • Reject unauthenticated requests and ignore any client-supplied UID.
  • Delete users/{uid} and known nested subcollections such as riddleStates and processedPurchases.
  • Delete public/user-owned rows such as leaderboard/{uid}.
  • Delete user-owned Storage files for avatars/exports when present.
  • Delete Firebase Auth user last and make missing resources idempotent.
  • Export the function from firebase-functions/src/index.ts.
