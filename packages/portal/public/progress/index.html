Known Risks

  • Bundle size Chunk warning is resolved and the portal no longer ships sourcemaps by default. Remaining cold-start cost is mostly React plus route UI copy; production web-vital budgets still need to be set.
  • Production provider gap Purchases and rewarded ads intentionally return not-configured behavior outside the fake harness until vendors are selected.
  • Deployment env gap The Vercel portal has Firebase web env vars and a live Clerk publishable key. The remaining web env gap is the production Firebase App Check site key.
  • Admin callable rollout The Vercel portal tolerates older callable responses, but Clerk-backed admin access and the new audit and leaderboard panels need the updated Firebase Functions code deployed for live data.
  • Clerk deployment secrets The isolated riddle-quest Vercel project has the live Clerk publishable key and proxy rewrite. Firebase Functions still need CLERK_SECRET_KEY; admins also need a Clerk JWT claim or Firestore admin document.
  • Custom subdomain ownership The portal can stay on riddle-quest-omega.vercel.app. A branded subdomain must be configured separately by the domain owner and must not replace, alias, or proxy the portfolio at roobsworld.com.
