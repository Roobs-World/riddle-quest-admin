Responsive App QA Todo List

Planning checklist for making every screen and modal scale correctly on Android and iOS phones and tablets.

Shared Foundations

  • Central responsive layout constants for content, auth, game slots, and modal dimensions.
  • Modal height clamping for tall fanfare/help/settings/shop modals.
  • Shared overlay/content wrappers cap width and height on tablet and small phones.
  • Safe-area wrappers use responsive padding instead of fixed screen assumptions.

Verification

  • Focused responsive/layout tests pass.
  • TypeScript check passes.
  • Known unrelated full-suite failures are documented.
  • Android emulator matrix is tested for responsive layout regressions.
  • iOS simulator verification is completed when local simulator tooling is available.
  • No skipped screens or modals: every checkbox in Screen Test Checklist, Game Modals, Help And Onboarding Modals, Settings And Profile Modals, Shop And System Modals, and Modal Infrastructure is completed.

Android Emulator Matrix

  • Small phone: Pixel 4a-class.
  • Standard phone: Pixel 7-class.
  • Large phone: Pixel 8 Pro-class.
  • Foldable outer display.
  • Foldable unfolded/tablet display.
  • Small tablet: 7-8 inch.
  • Large tablet: 10-11 inch.
  • Low-density tablet, if available.

The responsive design must be tested against the emulator matrix above to confirm every page and modal works as expected across Android phone, foldable, and tablet classes.
