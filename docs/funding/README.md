# Riddle Quest Funding Pack

This folder turns the funding plan into working materials for a sub-GBP 30k raise.

## Funding Positioning

Riddle Quest is a pre-launch mobile puzzle game that combines Wordle-style deduction with riddle solving, persistent progression, fair freemium monetization, and scalable content generation.

Primary ask: **GBP 24,500** to fund a focused 90-day beta, polish, evidence, and launch-preparation sprint.

Primary route: **non-dilutive grant first**, with publisher, investor, community, and bootstrapped revenue routes kept warm in parallel.

## Pack Contents

- [one-page-summary.md](one-page-summary.md): Send this as the first attachment or paste into application forms.
- [pitch-deck-outline.md](pitch-deck-outline.md): 10-slide deck copy and proof objects.
- [budget-and-runway.csv](budget-and-runway.csv): Funding ask, cost categories, and six-month runway assumptions.
- [grant-application-checklist.md](grant-application-checklist.md): UKGF-first application checklist and eligibility risks.
- [publisher-outreach.md](publisher-outreach.md): Publisher/investor outreach scripts and target criteria.
- [beta-validation-plan.md](beta-validation-plan.md): 100-300 player beta plan, survey, metrics, and dashboard spec.
- [two-minute-pitch-video-script.md](two-minute-pitch-video-script.md): UKGF-style video structure that shows game assets and route to market.
- [outreach-tracker.csv](outreach-tracker.csv): Lightweight CRM for publishers, grants, angels, platforms, and community partners.
- [90-day-execution-plan.md](90-day-execution-plan.md): Weekly execution checklist and acceptance gates.

## Immediate Next Actions

1. Confirm company eligibility: UK company age, PAYE status, employee/contractor structure, IP ownership, and subsidy history.
2. Record a 2-minute pitch video using the script in this folder.
3. Build the current Android preview and iOS TestFlight candidate for reviewers.
4. Fill the first 20 rows of `outreach-tracker.csv` with real publishers, grant contacts, and platform contacts.
5. Run a closed beta signup campaign and start collecting D1/D7 retention, completion rate, hint usage, ad opt-in, and IAP intent.
