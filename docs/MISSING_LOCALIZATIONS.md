### Priority Sections to Translate

1. **GameScreenAlerts** - User-facing error messages during gameplay
2. **RewardedAdPrompts** - Monetization-related prompts
3. **Profile** - User profile section strings
4. **Achievements** - Achievement notifications
5. **Credits** - Credits screen
6. **WelcomeModal** - First-time user experience
