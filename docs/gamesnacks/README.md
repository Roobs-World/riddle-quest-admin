# GameSnacks

The GameSnacks target is owned by `platforms/web/gamesnacks`. Read the [platform integration matrix](../common/architecture/platform-integration-matrix.md) for its capabilities and the [release quickstart](../common/releases/platform-release-quickstart.md) for packaging and handoff.

The target's release definition is `platforms/web/gamesnacks/release.json`. Use its public `pnpm release:gamesnacks` command to prepare the handoff.
