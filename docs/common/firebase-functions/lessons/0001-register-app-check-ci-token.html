Register an App Check CI token

Your win: run the real Jest browser test while production App Check remains enforced.

  1. Open Firebase Console for riddle-quest-ec2b2.
  2. Choose App Check → Apps.
  3. On web app 1:329028367192:web:b85776d379ea3356b7eb2d, open the overflow menu and choose Manage debug tokens.
  4. Create a token named jest-playwright-local and copy it into a password manager.
  5. Run the secure shell command from the project operations guide.

Success is a passing deployed Jest test with App Check enforcement still enabled.

Do not paste the token into chat, Git, an environment file, or any VITE_ variable.

Primary source: Firebase's web debug-provider guide.

Quick check: where should the token live? Answer: only in temporary or encrypted secret storage.
