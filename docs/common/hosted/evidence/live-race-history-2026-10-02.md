## Implementation

- A read-only Firestore transaction selects the newest 40 owned tickets in the exact locale and original seven-day creation window, then returns at most 20 validated terminal entries. Searching, unsettled, expired, future and corrupt authority is excluded. This bounded recent view can return fewer than 20 results; it is not a complete historical ledger. The displayed date is the original ticket creation time.
- Each entry is bound to the private ticket, provider/locale/category pool, match seats, run identity and committed result/reward receipt. Reads never settle a match, write a receipt or grant currency. A legitimate forfeit win can display its already committed 50-coin reward with zero correct answers. Public entries contain only the caller's opaque ticket, category, time, result, own score, bounded opponent presentation, availability and observed reward. Rival account IDs, answers and source decks remain private.
- The reader reuses the transactional live safety resolver for human opponents and checks current account existence, deletion and both block directions. Unavailable opponents lose their prior name, photo, level, score and actions. Bots retain a generic localized presentation and score without safety actions. A deleted owner cannot read history.
- Facebook explicitly enables the lazy authenticated history callable alongside its live safety capability. Reddit uses `/api/game/race.live.history` through the existing Devvit allowlist, signed gateway and shared account-operation lease. Its strict result is not passed through live profile hydration. No external browser request, provider SDK or canonical store is added to Reddit. The default Jest adapter does not expose the new history method.
- Activity combines Facebook's existing native context standings with recent live results; Reddit exposes Play, Activity and its game-owned Tournaments. History reads have an eight-second bound and retire on account, locale or tab changes. A confirmed block clears every visible row immediately before refreshing the private projection. Generic loading/error/empty text and the new title are translated in all 16 current locales. Scoped cards fit the tested mobile and desktop layouts.
- The Functions export audit now parses both local export lists and `from` re-exports independently. Regression fixtures prevent it from silently swallowing a following export block or counting erased type exports. Two Daily transaction test fixtures now use the existing locale-calendar helper instead of deriving a UTC date; production Daily behavior is unchanged.
