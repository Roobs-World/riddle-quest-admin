# Multiplayer harness delayed receipts

The deterministic browser race authority checked guess and Skip receipts before simulated transport delay but not afterward. Two overlapping deliveries could both observe a missing receipt. A wrong guess then consumed two attempts; correct guesses and fifth-attempt automatic skips could reject the second delivery after the first advanced the question. Both operations now recheck their receipt immediately after the delay and before active-question validation or mutation, returning their own original response type. Different receipts still represent different mutations. This fixes local authority fidelity; Firebase authority is unchanged.

Three original controlled delayed-guess regressions failed before the fix. Four final tests cover wrong/correct/fifth-attempt guess duplicates and explicit Skip duplicates. They release both delayed requests deterministically and assert equal successful responses, one canonical mutation, and one applicable 45-second charge. All pass; the focused fake-service and feedback-parity suites pass thirty-four tests. An initial edit used the guess response type in Skip, which the type/build gate caught; it was corrected and the final types and builds pass.

The actual React race browser harness verifies ten desktop/mobile cases: wrong, correct, fifth-attempt, explicit Skip and distinct-receipt control. Harness-owned canonical responses place input on the correct next row, preserve the expected score and penalties, and retain yellow keyboard feedback when applicable. All pass. Retained feedback/history cold and full reload checks pass eight cases. These are controlled local browser integrations, not hosted authority or deployment evidence.

At the final batch snapshot, the full client suite passes 1,938 tests across 240 suites, with 104 optional/browser tests and fourteen suites skipped. All seven configured isolated builds and artifact audits pass: Jest, Facebook, Reddit, YouTube, Netflix, Yahoo and GameSnacks. Portal types and source-size limits pass. Logs are retained under `artifacts/race-harness-delayed-receipts/`.
