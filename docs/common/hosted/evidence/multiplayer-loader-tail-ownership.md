# Multiplayer loader-tail ownership

It could also retain a handle after the callback fired before scheduling returned. Four public-seam regression cases fail before the fix; the normal asynchronous control passes. All five pass with the ownership guards.

RacePlay now advances tail generation and detaches the previous handle before cancellation. It checks generation after cancellation and clock observation, then holds the newly returned handle locally until scheduling settles. A retired unfinished timer is cancelled without overwriting the replacement timer. A callback that already completed leaves no retained handle for later disposal. The existing minimum loading delay and stale queued-callback generation check remain intact.
