# Riddle Quest Marketing Kit

Last updated: 2026-05-23

This folder implements the 90-day pre-launch marketing plan for Riddle Quest.

## Positioning

Primary promise: **A smarter daily word puzzle: solve riddles, not random words.**

Short pitch: Riddle Quest blends riddle solving with Wordle-style letter feedback, daily challenges, classic progression, coins, hints, achievements, leaderboards, and multilingual play.

## Operating Files

- [90-day launch calendar](launch-calendar.md): week-by-week work plan for pre-launch, launch, and optimization.
- [Creative production brief](creative-production-brief.md): screenshots, videos, static posts, and localization guidance.
- [Content calendar](content-calendar.md): 30-day organic content schedule plus reusable post formats.
- [Creator outreach](creator-outreach.md): target profiles, campaign package, tracking rules, and email/DM templates.
- [Press kit](press-kit.md): one-line pitch, boilerplate, launch announcement, founder angle, and asset checklist.
- [Tracking and KPIs](tracking-and-kpis.md): link taxonomy, analytics events, dashboard metrics, and acceptance criteria.
- [Pre-launch landing page](prelaunch-landing-page.html): static HTML page for waitlist/pre-registration traffic.

## Budget Default

First 90 days assumes a monthly budget of USD 1,000-5,000:

| Category              | Share | Use                                                                     |
| --------------------- | ----: | ----------------------------------------------------------------------- |
| Paid UA tests         |   35% | Jest, Meta/TikTok, and creator-link creative validation                 |
| Creator campaigns     |   25% | Micro-creator tests and usage rights                                    |
| Creative/localization |   20% | Video edits, screenshot exports, and translated assets                  |
| Tools/assets          |   10% | Hosted-page assets, attribution support, and design tooling             |
| Contingency           |   10% | Shift to the best-performing channel                                    |

## Launch Defaults

- Stage: pre-launch.
- Platform: Jest HTML5.
- Initial market posture: multilingual, with English assets finished first.
- Priority language groups: English, Spanish, Portuguese, French, German, Japanese, Korean, Hindi, Russian, Turkish.
- Main campaign theme: **7-Day Riddle Quest Challenge**.
