Accepted queue positions count toward the acknowledgement boundary: a successful older snapshot cannot clear the notice while newer state or failed preferences remain outstanding. A healthy save ahead of a retry acknowledges the latest state without an additional adapter write. Close/deletion and view cleanup retire recovery before draining already accepted operations. Queued retries capture their attachment and recheck it after queue and lock waits. They also recheck it between projection acknowledgement and a subsequent preference retry; a red test exposed that asynchronous retirement case before the additional guard.
