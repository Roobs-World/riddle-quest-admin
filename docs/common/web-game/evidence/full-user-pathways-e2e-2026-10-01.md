## Evidence model

Each pathway needs its UI entry, capability/identity preconditions, user action, request, authoritative result, rendered outcome, and reload/recovery result. A browser test using an injected host proves local integration behavior, not the real provider contract. An emulator test proves server behavior under its emulator configuration, not a production deployment. Real-host checks need the actual served version and test-owned identity. Unsupported capabilities need assertions that their controls and requests are absent.
