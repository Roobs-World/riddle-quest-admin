# Two-Minute Pitch Video Script

Target: UKGF-style application video and publisher reviewer intro.  
Runtime: 120 seconds maximum.  
Format: Gameplay-forward. Avoid a talking-head monologue and avoid a generic trailer.

## Shot Plan

### 0-10 seconds - Hook

Visual: App logo, then immediate gameplay: riddle visible, first guess entered.

Voiceover:

"Riddle Quest is an HTML5 word puzzle on Jest where every answer starts as a mystery. Instead of guessing random words, players solve a riddle, test guesses, and use color feedback to close in on the answer."

### 10-30 seconds - Core Loop

Visual: Riddle, keyboard input, feedback colors, second guess, solved puzzle.

Voiceover:

"The loop is instantly familiar: read the clue, make a guess, learn from the feedback, and solve within the attempt limit. The riddle gives each puzzle context, so the game feels more like deduction than repetition."

### 30-50 seconds - Modes

Visual: Daily Challenge entry, Classic Mode progression, tutorial or header state.

Voiceover:

"Daily Challenge gives players a short daily habit. Classic Mode gives them sequential progression through a growing puzzle set. Variable answer lengths let the game create more variety than fixed five-letter formats."

### 50-70 seconds - Retention And Monetization

Visual: Hint button, coins, achievement modal, profile/stats, and Jest shop.

Voiceover:

"Players earn coins, spend hints, unlock achievements, and track stats. Monetization is designed to be fair: normal play remains free and optional coin packs use Jest's purchase flow."

### 70-90 seconds - Technical Proof

Visual: Quick montage of app screens, backend/Firebase diagram if available, test output screenshot if readable.

Voiceover:

"The project is already a working React HTML5 game with Jest identity, Firebase-synced progress, server-authoritative rewards, Jest purchases, achievements, and a substantial automated test suite."

### 90-110 seconds - Funding Use

Visual: Three-column roadmap: Polish, Beta, Launch Readiness.

Voiceover:

"We are seeking GBP 24,500 for a focused 90-day sprint: polish onboarding and difficulty, complete accessibility and responsive-browser QA, create Jest page and pitch assets, run a 100-300 player beta, and produce the metrics needed for launch and publishing conversations."

### 110-120 seconds - Close

Visual: Gameplay win state, then funding ask screen with contact.

Voiceover:

"Riddle Quest is ready for the next step: measurable player validation. Funding this sprint helps de-risk launch while preserving the upside of original UK-developed puzzle IP."
