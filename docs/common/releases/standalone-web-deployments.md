# Historical standalone web and PWA deployments

As of 30 September 2026, the requested scope is platform-specific HTML5 builds
only. Standalone web hosting, Microsoft Store PWA, PWA Directory and PWAStore.io
builds are excluded. Their deployment and packaging commands have been removed;
release workflows and browser gates no longer build or require those artifacts.

Previous deployment and submission receipts remain historical evidence. Existing
hosted sites and provider listings have not been changed or deleted. The dashboard
marks their PWA destinations as excluded, including after a historical receipt
refresh, and schedules no further build or submission work for them.

Use the [platform release quickstart](platform-release-quickstart.md) for supported
commands. The shared provider-neutral source archive remains an intermediate input
for named HTML5 distributors such as itch.io; Netflix and Yahoo retain their
isolated candidate artifacts.
