Locale Gate + Riddle Localization Rollout

Single-source tracker for the staged cutover that combines the first-run language gate, locale-aware riddle content, canonical progress semantics, and locale-safe gameplay input.

Branch: codex/locale-gate-riddle-rollout | Tracker created: 2026-06-05 | Owner: Codex

Stage 0: tracker + branch Stage 1: language gate Stage 2: session plumbing Stage 3: backend cutover Stage 4: input hardening

Scope

UX

  • Promote the initial language screen to the official first-run entry point.
  • Persist locale locally and in the player profile.
  • Keep Settings as the post-onboarding language change surface.

Gameplay

  • Resolve riddle content by effective locale and canonical progress.
  • Keep classic and daily identity language-independent.
  • Refetch the active riddle after locale changes without resetting progress.

Backend

  • Add locale and canonical-key fields to player and riddle schemas.
  • Move Firestore reads and writes to locale-scoped paths.
  • Seed every supported locale before removing legacy shared paths.

Input

  • Make gameplay input grapheme-safe.
  • Add locale-specific keyboard layouts and normalization rules.
  • Cover RTL/LTR and board-width constraints.

Success Criteria

  • First-run users must explicitly choose a language before entering the app.
  • Locale changes update UI copy immediately and refetch the same canonical riddle slot.
  • Daily completion, hint usage, skip usage, and rewards are keyed to canonical challenge identity.
  • Every supported locale has seeded classic and daily content with no silent production fallback.
  • Lint, `tsc`, `fallow`, and targeted unit tests pass at the end of every stage.
