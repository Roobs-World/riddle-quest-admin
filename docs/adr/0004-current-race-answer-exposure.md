# Complete Race deck exposure for immediate play

Status: accepted

New Race clients may opt into receiving the complete immutable question, answer, and server-selected hint deck before the countdown finishes. This supports immediate local feedback and zero-wait transitions when a player requests a hint or skips a riddle. A player can inspect every answer in browser memory, so the deck is a responsiveness feature rather than an anti-cheat boundary. Competitive time, scoring, penalties, advancement, and rankings still require server confirmation. Legacy responses remain answer-free.
