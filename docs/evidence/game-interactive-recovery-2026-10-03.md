# Interactive game surface recovery — 2026-10-03

Failed modal and multiplayer module downloads, React subtree errors, and target-owned multiplayer render errors previously reached the fatal page boundary. Opening one optional surface could remove the entire game, including its current answer and authoritative session.

`GameSurfaceBoundary` now retires only the failed interactive surface for the current account visit. The frame, host bridge, typed draft, session token and queued operations stay mounted. An accessible localized recovery dialog restores the game through Close and preserves the existing server-authoritative Hint, Classic Skip and Continue confirmations. A winning puzzle keeps its Next action available after completion acknowledgement. Next releases the normal victory loading guard before requesting the successor. Declining Continue returns to the existing loss flow; recovery does not invent a next puzzle for a loss. Classic Skip remains available when the full modal module has failed.

Recovery owns focus, traps Tab traversal, respects disabled actions and Escape, and leaves underlying game controls inert. An offline or host activity overlay also prevents recovery's keyboard handler from acting through that overlay. Reopening a retired surface does not repeat its diagnostic. Existing translated keys and authoritative prices are reused. The small coin confirmation components are shared with normal modals; the full modal module and its treasure asset remain lazy.

The production replay exposed two paid-continuation races. A directly submitted guess without a durable journal could expose an actionable Continue button even though the recovery module could not accept that purchase yet. `coinActionsReady` now supplies the real readiness to normal and fallback prompts. Durably journaled answers can still queue their paid action immediately, in order. Separately, confirming the fifth guess no longer reopens Continue after its extra attempt has already been granted provisionally. Rapid activation retains one request identity and produces one authoritative spend.
