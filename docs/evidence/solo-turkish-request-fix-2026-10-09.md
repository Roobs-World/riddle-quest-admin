# Hosted single-player Turkish request fix — 2026-10-09

The real reducer already produced `İ` from Turkish `i`; previously a later Hint, a persisted Hint journal, or a completed displayed word could be rejected by ASCII-only validation. The [diagnostic audit](solo-locale-request-audit-2026-10-09.md) retains four reproduced failures and two passing controls.

A shared pure keyboard-letter predicate now defines ASCII letters plus those two display variants. Bridge and callable Guess/Hint schemas reuse bounded shared input schemas; the pending journal uses the pure predicate without importing Zod into its recovery reader. Submitted words remain limited to seven supported cells and partial attempts to seven single-letter/empty slots. Unsupported scripts, combining sequences, whitespace, controls and oversized input remain rejected. No input transformation occurs: exact request bytes and receipt IDs are retained. Canonical answer policy is unchanged.
