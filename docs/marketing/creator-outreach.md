# Creator Outreach

Last updated: 2026-05-23

## Target Creator Profiles

Prioritize micro-creators with engaged audiences over broad gaming channels.

| Segment                     | Audience Signal                                    | Best Content Ask                           |
| --------------------------- | -------------------------------------------------- | ------------------------------------------ |
| Puzzle solvers              | Wordle, crosswords, riddles, logic puzzles         | Solve today's riddle on camera             |
| Brain teaser creators       | Daily questions, quiz posts, "can you solve" hooks | Challenge audience before answer reveal    |
| Language creators           | Vocabulary, translation, language learning         | Show the same riddle in multiple languages |
| Cozy/browser game creators  | Casual games, daily routines                       | "My new daily puzzle habit"                |
| Teachers/education creators | Classroom riddles, vocabulary games                | Brain warmup or bell-ringer style post     |

## Outreach Targets

- Warmup: contact 30-50 creators.
- Launch: publish 10-20 posts.
- Optimization: repeat with the top 2-3 creator segments.

## Offer Structure

Default package:

- 1 short-form video, 20-45 seconds.
- 1 story/community post where available.
- Usage rights for 30 days for paid amplification.
- Tracked link or code per creator.
- Fixed fee for the first test; performance bonus only after tracking is reliable.

## Tracking

Use this naming format:

`rq_[creatorhandle]_[platform]_[language]_[yyyymmdd]`

Example:

`rq_puzzlealex_tiktok_en_20260615`

## Creator Brief

Required talking points:

- Riddle Quest is a riddle-based word puzzle game.
- You solve clues with color feedback.
- There is a daily challenge and classic levels.
- The game supports multiple languages.
- CTA: "Try Riddle Quest" or "Join the 7-Day Riddle Quest Challenge."

Avoid:

- Calling it official Wordle.
- Promising winnings, prizes, or cognitive/medical benefits.
- Showing fake gameplay.
- Saying purchases are required.
