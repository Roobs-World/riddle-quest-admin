The final injected fixture uses production RaceGameplay (including NativeAnswerInput and ControlledGuessBoard), editRaceInput, RaceDrafts with actual localStorage, raceAttemptState, both shared guess request schemas, hint and feedback schemas, and all three production style sheets. Before/after hashes prove the imported selected production inputs did not change during the run. Fixture source and both bundled React modes are retained here.

Each case checks exact complete native cells, one committed callback, composition hold where applicable, same-question persistence across a real document reload, complete NFC decoding through recorded and live request schemas, full feedback/history cells, full hint cells and accessible labels, disabled green hints, and recovery of hint/history presentation. All160 intermediate and final document snapshots additionally have empty captured error, unhandled-rejection and console-error arrays. Each browser retains sixteen full-page screenshots.

Scope: IME and paste events are injected into the actual browser DOM; this does not certify an OS IME or system clipboard. The hints and confirmed rows are schema-valid display-only fixture receipts retained in a harness sessionStorage key; the browser fixture does not assert server scoring, rewards, multiplayer transport, or paid mutation authority. Core/backend/real SDK checks are handled by the parent. This fixture validates these UI and persistence seams rather than full-game layout or glyph legibility for127 stacked combining marks. Native editor styles and complete DOM/accessibility text are checked; font shaping is browser-specific.
