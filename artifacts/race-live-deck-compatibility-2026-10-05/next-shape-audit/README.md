This offline Node probe transpiles current production modules into the clearly owned `transpiled/` evidence tree, then invokes actual catalog validation, shared schemas, frozen/live deck guards, editRaceInput, liveRun and applyRaceGuess/applyRaceHint. Thirty selected loaded source files are hashed before use and verified unchanged afterward. No prepare command, emulator, browser server, credential inspection, or production policy edit was used.

The current catalog, shared evaluation schema and frozen/live deck guards accept original answer `a b` as three grapheme slots. The actual editor discards the internal space and produces `[a,b,empty]`. Its joined guess `ab` passes the transport schema but the actual engine rejects it with `invalid-argument: Guess must contain exactly3 characters.` The draft is incomplete, so normal UI submission would be disabled. Single-letter insertion also refuses the space. Two actual authoritative hints reveal `a` and then the space; after filling the final `b`, the same engine scores `a b` correctly with30,000ms hint penalties. This isolates a current admission/editor shape mismatch without selecting a policy change.

All16 examples/152 assertions passed as diagnostic expectations: nine internal whitespace forms (space, tab, LF, CRLF, NBSP, narrowNBSP, ideographic space, thin space, and BOM/ECMAScript trim whitespace) enter the catalog but are discarded by the editor and cannot form their authored guess. Seven controls (hyphen, apostrophe, digit, emoji, emoji ZWJ family, zero-width space, and ordinary letters) are preserved and score correctly through the actual editor/engine. U+200B zero-width space is a retained control, whereas U+FEFF is removed by ECMAScript trim. This distinguishes the reproduced behavior from a broader letters-only or punctuation policy.
