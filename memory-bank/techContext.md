# Tech Context

## 1. Technologies Used

- Firebase (Authentication, Firestore, Cloud Functions, Storage)
- Node.js (for Firebase Functions)
- TypeScript (for Firebase Functions)
- Jest (for testing Firebase Functions)
- ESLint (for linting)
- Prettier (for formatting)

## 2. Development Environment Setup

- Node.js and npm installed.
- Firebase CLI installed and configured.
- Google Cloud SDK (if interacting with Google Cloud services directly).

## 3. Technical Constraints

- Firebase platform limitations (e.g., function execution time, Firestore query capabilities).

## 4. Dependencies

- Refer to `firebase-functions/package.json`.

## 5. Tool Usage Patterns

- `npm run deploy` for deploying functions.
- `npm run lint` for linting.
- `npm run test` for running tests.
