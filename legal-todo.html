Legal And Security Release Todo List

Release-blocking checklist for Firestore write controls, callable function protection, dependency audit cleanup, and app-store/legal disclosure readiness.

Last updated: 2026-05-23. Status: open checklist.

Firestore Write Controls

  • Lock Firestore economy, progress, and stats writes to Cloud Functions only.
  • Review Firestore rules for all client-writable economy/progress/stats paths and deny direct client writes.
  • Confirm Cloud Functions use server-side validation and trusted user ids from auth context only.

Callable Function Protection

  • Add auth/admin checks and App Check to generation and admin callables.
  • Require request.auth for user-scoped generation callables.
  • Require explicit admin claims for admin-only callables and reject non-admin users.
  • Set enforceAppCheck: true on protected callables where supported.

Dependency Audit

  • Patch or override vulnerable dependencies.
  • Use the Expo-recommended install flow for Expo package changes.
  • Rerun pnpm audit --prod and record the remaining findings, if any.

Legal And Store Readiness

  • Add privacy policy, terms/EULA, third-party notices, data deletion/export paths, and accurate Apple/Google store disclosures.
  • Publish or link the privacy policy and terms/EULA from the app and store listings.
  • Document third-party services, SDKs, licenses, data categories, and purposes in third-party notices.
  • Verify account deletion and data export request paths are discoverable and functional.
  • Ensure Apple App Privacy and Google Play Data Safety answers match actual app behavior.

Check items only after implementation, audit evidence, and store/legal review are complete.
